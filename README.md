# How to Run Python in VS Code




This guide helps beginners learn how to use Python in VS Code.

It covers how to set up Python, create a file, and run a simple program.

\## Getting Started

First, download Python and VS Code onto your computer.
Once both are installed, open VS Code and install the Python extension.
After that, you can create a Python file and start writing code.

## How to Run Python in VS Code

First, open VS Code and create a new Python file
Name the file hello.py and type
print("Hello, World!")
Save the file and open the terminal in VS Code.
Type python3 hello.py and press Ente
The program should display Hello, World! in the terminal
